# Hydro Yearbook Digitizer（水文年鉴自动提取）

[English](README.md) | 简体中文

面向扫描件和拍摄件水文年鉴的可追溯提取工作流与 Codex Skill。它将站点一览表、月均/年均总表、单站单变量日值表转为干净的 Excel，同时保留独立的质检和来源证据。

## 适用范围

- 中国水文年鉴、流域水文资料汇编等固定表格版式；
- 水文站一览表、变量可用性表、月均/年均汇总表；
- 31 天 × 12 月的单站日值表；
- 横拍、旋转、斜拍、双页跨页、晚月续页、连续空行与表格线不完整的页面。

不适用于凭 OCR 文本顺序直接拼表，也不用于根据流量和含沙量推算源表没有印出的输沙率等变量。

## 核心原则

1. **先认源，再识别。** 封面、当前页表头和当前行是权威证据；文件夹名、往年站表和旧 Excel 只能辅助核对。
2. **站名和行号不可串。** 表名中的河名、站名、括号限定词、变量、单位和当年序号构成一个原子身份。不同变量章节不能仅凭序号关联。
3. **跨页先对齐物理行。** 右页 10—12 月的每一行都要对应左页当前行；空行、分段标题和序号重启都必须保留行槽，不能让后续数据上移。
4. **日值先建格，再读数。** 每月按自身物理表格线注册；日值存在 5、10、15、20、25 日后的五个间隔带，30 日后没有额外间隔。首行、末行、短月和 10—12 月必须重点检查。
5. **不把空值变成 0。** 源表空白、河干/渠干/冰情等状态、扫描缺失和未解决 OCR 必须区分。无证据的数值不允许进入交付表。
6. **年均用于复核，不替换源数。** 年均值必须从源表独立读取；与按月、按日计算的结果不一致时复核源格，确认后保留源表冲突记录。
7. **整数不要显示 `.0`。** 表格使用 `General` 或按单元格使用 `0` / `0.######`，并在回读时检查格式。

## 标准交付目录

```text
<流域>/
├─ 站点与目录索引.xlsx
├─ 提取复核记录.xlsx
├─ 数据范围与缺失说明.xlsx
├─ 处理指标记录.xlsx
└─ <年份>/
   ├─ 月值/
   │  └─ <年份>-<流域>-<变量>-月值总表.xlsx
   └─ 日值/
      └─ <变量>/
         └─ <序号>-<河名>-<站名>-<变量>-日值表.xlsx
```

- **月值总表：** 一个变量一张大表；每站一行，含 1—12 月、源表年均值、单位和来源页。
- **日值表：** 一站一变量一张表；主表为 31×12 日历矩阵，另含月统计、元数据、说明。
- **站点与目录索引：** 包括站号、水系、河名、站名、地址、分开的经纬度、建站时间、来源页，以及年份/变量/表类型/文件路径的可用性索引。
- **质检记录：** 交付 Excel 尽量简洁；OCR 候选、裁切图和详细审计单独存放，不污染数据表。

## 使用方式

在仓库根目录安装开发依赖：

```bash
python -m pip install -e ".[image,dev]"
pytest -q
```

Skill 入口位于：

```text
.agents/skills/hydro-yearbook-digitizer/SKILL.md
```

将该文件夹放入 Codex 可发现的 Skill 目录，或在本仓库作为工作区时显式调用：

```text
$hydro-yearbook-digitizer
```

常用 CLI：

```bash
hydro-yearbook init --root ./资料库 --basin 永定河流域 --year 1962
hydro-yearbook photos-to-pdf raw/photos/*.jpg --output work/documents/source_browse.pdf
hydro-yearbook --help
```

照片转出的 PDF 仅用于阅览、页序检查和定位；原始照片/PDF 必须保留，真正识别使用原件或已记录的透视矫正图。

## 复核与交付要求

最终交付前必须满足：

- 所有需要的页面和逻辑表均已清点，且输出文件齐全；
- 每个数值、空白和状态均有来源证据；
- 所有适用的身份、表格几何、日历、类型、年均和跨表检查通过，或有明确的源表冲突记录；
- 未解决 OCR / 行列对齐问题的**数量为 0**；
- 每个 Excel 已重新读回并与最终数据矩阵比对；
- 指标记录区分渲染、OCR、人工复核、导出回读耗时，并只报告真实获得的外部 API token 遥测。

本 Skill 的目标是避免“静默错误”，并不承诺模糊源图可以自动达到 100% 正确。无法从原始证据判断的格子应继续复核、补图或明确标记，而不是猜测。

发布 ZIP 包含 Codex Skill 与全部公开文档；Python wheel 仅包含可复用库和 CLI。使用 Codex 时，请从 ZIP 中安装 `.agents/skills/hydro-yearbook-digitizer` 文件夹。
